# DarbSec - دربك الآمن للسايبر

مشروع تعليمي - محفظة أعمال (Portfolio) لـ Fahad Al Subaei، يساعد المستخدم على اختيار الشهادة المناسبة في الأمن السيبراني حسب دوره، ويعرض المعاهد في مدينته. ليس شركة ولا خدمة رسمية ولا جهة معتمدة.

## التشغيل

افتح index.html مباشرة أو ارفع ملفات المجلد على GitHub Pages. لا حاجة إلى تثبيت أو أوامر تشغيل.

## النشر على GitHub Pages

Settings > Pages > Deploy from branch > main > / (root)

ارفع محتويات هذا المجلد بحيث يكون index.html في جذر المستودع. جميع روابط الملفات المحلية نسبية.

## الخصوصية

لا يتم جمع أي بيانات شخصية: لا بريد إلكتروني، لا جوال، لا تتبع. لا حسابات ولا إرسال بيانات. تعمل الصفحة دون اتصالات خارجية؛ روابط المعاهد تفتح فقط عند اختيارها.

يستخدم الموقع sessionStorage لاختيارات الدولة والمدينة والدور فقط، بالمفاتيح darbsec_country وdarbsec_city وdarbsec_role، بالإضافة إلى علامة darbsec_counted للعداد. لا تُحفظ الإجابات أو النتائج، وتبقى في ذاكرة الصفحة. تنتهي الاختيارات بانتهاء جلسة التبويب. تغيير المدينة يمسح الاختيارات ويعيد الإعداد من خطوة المدينة، ويحتفظ بعلامة العداد لتجنب الزيادة المتكررة.

العداد محلي بسيط للجلسة الحالية، يعرض زيارة واحدة ولا يزيد عند التحديث؛ ليس مجموع زيارات جميع الأجهزة. لا يوجد إجمالي عالمي لأن المشروع ثابت بالكامل ولا يستخدم خدمة خارجية.

## الاختبار والمعاهد

حُفظت جميع أسئلة البنوك الأصلية وأوزان الإجابات وترتيب الشهادات وخريطة النتائج. الطالب يستخدم بنك الطلاب، والمتدرب بنك الخريجين، والموظف بنك الموظفين، والخبير بنك الخبرة الافتراضي الأصلي (1–3 سنوات)، ودور أخرى بنك الطلاب. بقيت بنوك الخبرة الأخرى في البيانات دون إضافة سؤال إضافي خارج خطوات الإعداد المطلوبة.

حُفظت بيانات الشهادات والجهات التدريبية الأصلية. لكل جهة city؛ الجهات التي لا تتوفر لها مدينة سعودية موثقة تحمل Other، ولا تُعامل كفروع محلية. أضيف سجل فرع جدة للجهة الموجودة أصلًا «شركة الخليج للتدريب والتعليم». تعرض النتائج جهات المدينة المحددة، أو أقرب مدينة موثقة حسب المسافة التقريبية بين مراكز المدن، مع التنبيه المطلوب. اختيار Other يعرض جميع الجهات.

## الملفات

- index.html: الصفحة والاختبار والنتائج.
- css/style.css: تنسيقات المشروع الأصلية بعد التنظيف وتعديلات التوافق.
- js/data.js: الشهادات والمعاهد مع city.
- js/main.js: الأسئلة والتقييم والتدفق وفلترة المدن.
- assets/: صور الشهادات والدورات الموجودة سابقًا.
